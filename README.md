⚔️ BattleDudes 2D Top-Down Shooter
A fast-paced, action-packed 2D top-down arena shooter game built with p5.js, Web Audio API, and Tailwind CSS. Inspired by browser battle royale and top-down shooter classics like BattleDudes.io, Mini Royale, and Surviv.io.
✨ Features
🎯 6 Unique Weapons: Pistol, AK-47, Shotgun, Sniper Rifle, Rocket Launcher, and Grenade Launcher—each with unique recoil, bullet velocity, spread, and reload mechanics.
🤖 Smart Bot AI: Fight dynamic computer bots that patrol, target, strafe, and hunt down opponents across the battlefield.
🎨 Character Customization: Customize your Dude's skin color, primary weapon, and headgear (SWAT Helmet, Tactical Cap, Headphones, Beanie, Royal Crown).
🔊 Procedural Sound Engine: Powered by Web Audio API for custom synthetic gunshots, reload sounds, explosions, and hit indicators with zero external sound files.
💥 Destructible Environment & Hazards: Shoot open wooden crates for cover clearing, hide in bushes for stealth invisibility, and detonate red barrels for splash damage.
📱 Dual Touch Joysticks: Full mobile & touch screen support with virtual movement and aim joysticks.
📊 Real-Time Match Stats: Leaderboards, kill feed, damage tracker, accuracy calculator, and streak counters.
🎮 Controls
Desktop (Keyboard & Mouse)
WASD / Arrow Keys: Move character
Mouse Movement: Aim crosshair
Left Mouse Click: Fire weapon
1 - 6 Keys: Switch primary / secondary weapons
R Key: Reload current weapon
P / Esc Key: Pause / resume game
Mobile / Touch Devices
Left Joystick: Drag left side of screen to move
Right Joystick: Drag right side of screen to aim & auto-fire
On-Screen Buttons: Tap hotbar slots to swap weapons, tap reload button to reload
🛠️ Tech Stack & Requirements
HTML5 & CSS3
JavaScript (ES6+)
p5.js - Canvas rendering, physics math, vector calculations
Tailwind CSS - UI overlay styling & responsive layout
Web Audio API - Dynamic sound synthesis
No build steps or Node.js dependencies required! The app is 100% client-side and runs directly in any modern browser.
🚀 How to Run Locally
Clone or download this repository.
Open index.html directly in any web browser (Chrome, Firefox, Edge, Safari).
Click "DEPART TO BATTLE" and enjoy!
